# Allicode

Um projeto educacional full-stack em JavaScript desenvolvido para alunos do primeiro período dos cursos de graduação do **CEFET**.

**Allicode** apresenta o desenvolvimento web moderno por meio da prática utilizando:

- **Frontend:** React + Vite  
- **Backend:** Express (Node.js)

---

## ⚛️ Frontend Stack

Construído com **React** e **Vite**.

Tópicos abordados:

- Components  
- Props  
- Hooks  
- State management  
- Forms  
- Routing  
- API requests  
- Project structure  
- Reusability  

---

## 🖥️ Backend Stack

Construído com **Node.js** utilizando **Express**.

Tópicos abordados:

- HTTP fundamentals  
- REST APIs  
- Routes  
- Controllers  
- Middleware  
- CRUD operations  
- Error handling  
- Simple architecture

## 🔧 Commit Convention

Use mensagens de commit simples e padronizadas.

### Format
<b>tipo</b>: descrição curta

#### Examples
```bash
feat: create login page
fix: correct navbar responsive bug
docs: update installation guide
refactor: separate auth controller
test: add user route tests
chore: update dependencies
```

## 🌿 Branches

Para manter o projeto organizado e facilitar o trabalho em equipe, utilize branches para cada tipo de alteração.

---

### Common

- `main` → versão estável e pronta para produção  
- `develop` → branch de desenvolvimento e integração de novas funcionalidades  

---

### Convenção de Nomes

Utilize nomes curtos, claros e em inglês.

#### Format

<b>tipo</b>/nome-da-tarefa

#### Examples

```bash
feature/login-page
feature/student-dashboard
feature/api-auth

fix/navbar-mobile
fix/form-validation

docs/readme-update

refactor/user-service

test/auth-routes

chore/update-dependencies
```
